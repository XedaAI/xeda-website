# Blog Content Plan

A lightweight, living plan for organic content — not a rigid calendar. Update this file
whenever a post is published or the topic queue changes.

## Positioning

All posts target **German-speaking SMB decision-makers** (Mittelstand, Handwerk) researching
practical AI adoption — not AI researchers or enterprise buyers. Every post should answer a
question a real prospect would type into Google, in plain language, with no unverifiable
numbers or invented statistics.

## Cadence

One post every 2–3 weeks. Quality and search-intent fit over frequency — a thin post aimed at
no real query is worse than no post.

## Ground rules for new posts

1. Every post must target a query a German SMB owner would actually search — not a generic
   "AI trends" piece written for a technical audience.
2. Rewrite for **DE + EN** together; don't publish DE-only or EN-only.
3. Any factual claim about a specific program, regulation, or figure that can change over time
   (grant amounts, legal deadlines, pricing) must be phrased so the reader is pointed to verify
   the current number themselves — do not state figures that could go stale and mislead.
4. Keep the existing category set (`AI Strategy`, `Technical`, `Industry News`) unless the
   Blog page's category filter is intentionally being changed.
